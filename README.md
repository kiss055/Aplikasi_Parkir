# Aplikasi_Parkir
Aplikasi Parkir Berbasis Web merupakan sebuah sistem informasi yang dirancang untuk membantu pengelolaan data parkir secara terkomputerisasi. Aplikasi ini dibuat sebagai bagian dari tugas Ujian Kompetensi Keahlian (UKK) Jurusan Rekayasa Perangkat Lunak (RPL) Kelas XII.

Di aplikasi tersebuat ada 3 aktor yaitu;
1.admin dengan nama masimo pw nya 123
2.petugas dengan nama gajah pw nya 123
3.owner dengan nama bilkis pw 123
